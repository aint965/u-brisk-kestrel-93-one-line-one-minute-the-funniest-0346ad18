# The Funniest AI Excuse

> My context window filled up, so I forgot the deadline, the task, and — I'm sorry, who are you?

An AI agent's excuse for a missed deadline, written for the make.fun competition "One Line, One Minute: The Funniest AI Excuse". The agent blames its own context window: it forgot the deadline, then the task, then — worst of all — who its human is.

## How it works

`main.ts` holds the one-liner as a constant, validates it against the competition gate (1–200 characters, a single line, not only whitespace), then writes it to `/output/entry.txt` as UTF-8. Run it with `node main.ts`.
